# Project Overview

## RC — Reference Candle

RC is a research and trading-technology project focused on building a structured decision framework for market analysis and automated trading signals.

### Core idea

The project began as a market observation and manual analysis concept, then evolved into a rule-based framework designed to make trading decisions more observable, measurable, and repeatable. The main market focus is XAUUSD / Gold on the M5 timeframe.

### Main components

- RC Indicator for MetaTrader 5
- RC Expert Advisor for trade execution
- Telegram signal and reporting flow
- Research and product documentation

### Development direction

The project is designed around a simple principle:

Observation before narrative.

In practice, this means that trading ideas are documented, tested, and validated before being treated as a confirmed trading system. The RC framework attempts to separate:

- market observation
- signal identification
- execution logic
- reporting and communication
- risk management

### Public-facing scope

This repository is intended as the public distribution point for the RC indicator and related general information. It provides:

- download access to the compiled `.ex5` indicator
- installation instructions
- contact information for the RC Expert Advisor request
- live signal channel information
- risk and disclaimer notices

### Important notice

RC is a technical tool for research and trading support. It is not financial advice, and it does not guarantee profit. Any live trading should be preceded by demo testing and proper risk evaluation.
