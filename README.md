# RC Monitor Phase 3

**RC Monitor Phase 3** is a compiled indicator for MetaTrader 5, distributed as an `.ex5` file. This repository provides the public download and basic installation information.

> Before using the indicator, review its behavior and test it in a demo environment. Trading involves risk; the indicator does not guarantee results.

## Download

Download the latest available binary from this repository:

- [`RC_Monitor_Phase3.ex5`](./RC_Monitor_Phase3.ex5)

For version history and release-specific downloads, see the repository's [Releases](../../releases) page when releases are available.

## Installation

1. Download `RC_Monitor_Phase3.ex5` from this repository.
2. In MetaTrader 5, select **File → Open Data Folder**.
3. Open `MQL5/Indicators` inside the data folder. Create a subfolder such as `RC` if you want to keep it organized.
4. Copy the `.ex5` file into that folder.
5. Return to MetaTrader 5, right-click **Navigator → Indicators**, and choose **Refresh** (or restart MT5).
6. Find **RC_Monitor_Phase3** in Navigator and attach it to a chart.

If the indicator does not appear, confirm that the file is in the correct terminal's data folder and that MetaTrader 5 can load the binary.
